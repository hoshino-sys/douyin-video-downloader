夜星视频下载器 v5.9.1
====================

支持平台：抖音 / TikTok / Bilibili / YouTube

本次更新（5.9.1）：
- 项目结构整理：历史数据库文件自动迁移（旧版本数据无需任何操作，首次启动自动保留）
- 精简安装包体积与无用文件；修复requirements依赖声明（二维码登录所需 qrcode）
- 其余与 5.9 相同：Cookie 分平台状态、实时下载进度、任务卡片改版、应用内更新

使用说明：
1. 无需安装 Python，双击「夜星视频下载器.exe」即可启动
2. 首次启动会提示配置 Cookie，推荐「从浏览器导入」：一键导入本机浏览器中已登录的抖音/TikTok/B站/YouTube Cookie（未登录的平台会提示失败，不影响其他平台）
3. 粘贴链接：点击「粘贴」按钮或按 Ctrl+V；复制分享链接后切回本窗口会自动填入
4. 平台自动识别：直接粘贴链接即可，无需手动选择平台（抖音/TikTok/B站/YouTube）
5. 常见功能：
   - 图集下载：解析后点击缩略图下载单张，或「下载全部」
   - 打开文件位置：任务卡片右侧文件夹图标（无需展开）
   - 批量下载：勾选「批量下载」，每行一个链接，自动识别平台（支持混合）
   - 自定义保存位置：点击「保存到」选择文件夹，留空使用默认目录
   - B站/YouTube 批量：粘贴 UP主空间 / 频道 / 播放列表链接即可
   - 画质：默认最高画质（自动合并最佳视频+音频），单视频可切换清晰度
   - 实时日志：任务卡片可展开查看下载进度与日志
   - 应用内更新：设置 → 关于 → 检查更新（需能访问 GitHub）

目录说明：
- 夜星视频下载器.exe : 主程序
- backend/           : 内置后端（免 Python 环境，请勿移动其中的文件；ffmpeg 已内置其中）
- ffmpeg.exe / ffprobe.exe : 音视频合并组件（已内置，无需安装）
- Volume/            : 下载文件与配置保存位置（首次启动自动创建）

常见问题：
- 顶部提示某平台「未导入」：点击对应图标或右上角钥匙图标导入该平台 Cookie；
  全部导入后提示条自动消失
- B站/YouTube 高清画质需要登录态：右上角钥匙图标 → 一键导入全部 Cookie
- Chromium 内核浏览器导入 Cookie 需先关闭浏览器；失败可尝试管理员身份运行
- YouTube 提示「已导入 Cookie 但仍触发风控」：多为当前网络/代理节点 IP 被
  YouTube 风控（Cookie 本身有效），更换网络环境或代理节点后重试即可
- 提示「缺少可用的 JavaScript 运行时」：解析 YouTube 需要内置的 qjs.exe
  （位于 backend/_internal/），报此错说明安装包不完整或文件被杀毒软件隔离，
  请重新解压完整安装包（勿经 QQ/微信中转压缩包）
- 提示「未找到 ffmpeg」：本程序已内置 ffmpeg（程序根目录和 backend/ 内各一份）。
  若仍报此错，说明文件被杀毒软件（360/Defender 等）隔离或解压/传输时丢失，
  请恢复被隔离的 ffmpeg.exe 或重新解压本程序（勿经 QQ/微信中转压缩包）
- 启动报「后端服务启动失败」：多为环境问题——①杀毒软件隔离了 backend/ 内
  文件（恢复被隔离文件或将本目录加入白名单后重新解压）；②压缩包解压不完整
  或经 QQ/微信中转损坏（重新获取完整压缩包）；③系统区域非中文时程序路径含
  中文可能初始化失败（把文件夹移到纯英文路径如 D:\yx_dl 再试）。
  弹窗内「后端日志」末尾行可用于定位，反馈问题时请一并发送
- 检查更新提示「无法连接更新服务器」：多为当前网络访问 GitHub 受限，
  挂代理后重试，或直接到发布页下载：https://github.com/hoshino-sys/douyin-video-downloader/releases
- 如何确认版本：设置页「关于」可查看版本号（本版本为 5.9.1）
